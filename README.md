# 🏫 풍산고에서 졸업하기

15턴을 버티고 풍산고를 졸업하는 텍스트 육성 게임입니다.

- `index.html` — 브라우저에서 바로 플레이하는 웹 버전 (설치 필요 없음)
- `pungsan_game.py` — 원본 Jupyter(ipywidgets) 버전

## 배경
경북 안동시 풍산읍, 논밭 한가운데 있는 **전원 기숙사 학교**. 학사 일정은 2026학년도 풍산고 학사일정표를 바탕으로 했다.

## 규칙 (웹 버전)
- 이름을 정하고 집중할 능력치 하나를 고르면 그 능력치 +10 (모두 45에서 시작)
- 한 학년 = 5시기(3~4월 / 5~6월 / 7~8월 / 9~10월 / 11~2월), 3년 = 15턴
- 한 턴 흐름: 🏠 귀가 → 🛒 매점 → 📅 학사일정 → ⭐ 활동 → 🎲 돌발 사건 → 📝 시험 → 🌙 정리
- **🏠 귀가**: 한 달마다 귀가는 필수(용돈 돌림판 + 스트레스 회복), 사이사이 격주 주말엔 귀가할지 잔류할지 선택
- **📅 학사일정 이벤트**: 전통문화체험(병산서원·하회마을 / 도산서원), Project Bridge(3학년), 체육대회, 문경새재 과거길 걷기, 학생회장 선거, 1학년 야영체험, 2학년 수학여행(관광 코스 / 일본 학교 방문 중 선택), 봉황축제, 수능 D-100, 수능 전날
- **📝 시험 (1~3학년 공통)**: 3·6·9월 모의고사(9등급제)와 1·2학기 중간·기말(내신 5등급제)이 실제 일정대로. 3학년 2학기 기말 대신 수능
- **😵 스트레스**: 매 턴 쌓인다. 70 이상이면 모든 성공률 -10%·시험 실력 하락, 100이면 번아웃
- **🚨 기숙사 벌점**: 무단외출 적발·야식·폰·점호 지각·방 검사… 10점이면 부모님 호출, 20점이면 강제 퇴사(퇴학)
- **🎲 돌발 사건**: 매 턴 발생. 기습 방 검사, 점호 지각, 복귀 버스 놓침, 운동장 고라니, 와이파이 먹통, SNS 사진 유출(무단외출 후) 등
- **⚔️ 라이벌 찬동**: 시험마다 등급 대결
- **🧠 벼락치기 퀴즈**: 시험·수능 직전 상식 퀴즈(일반 3문제, 수능 5문제, 문제당 12초). 계산 없이 배경지식으로 푸는 150문제(국어·영어·한국사·사회·수학 상식·과학·안동 상식·예술). 학년이 오를수록 어려운 문제(★~★★★) 비중이 커지고, 문과는 국어·영어·한국사·사회, 이과는 수학·과학 위주
- **🛏️ 3인실 룸메이트**: 입학 때 심예준·한유민·김대현·정재원·찬동(라이벌!) 중 2명. 친밀도는 각자 따로. 두 사람 평균이 70 이상이면 매 턴 스트레스 -3, 25 이하면 +4. 룸메마다 전용 사건이 있다
- **🎒 반입 금지물품**: 귀가 후 복귀할 때 하나씩 몰래 챙겨 내 옷장이나 룸메 옷장에 숨긴다 — 🫖 전기포트(체력 감소 -3), 🔥 전기매트(체력 +3, 겨울 스트레스 -3), 📱 공기계(사회성 감소 -3, 스트레스 -2), 💡 독서등(지능 감소 -3), 🎮 휴대용 게임기(스트레스 -5). 복귀 짐 검사 25%, 불시 방 검사 물건당 15%, 내 옷장에서 걸리면 압수 + 벌점 4, 룸메 옷장에서 걸리면 벌점은 룸메가 받지만 들통나서 사회성 -15·그 룸메 친밀도 0 (단, 한유민 옷장에서 나온 게 전기포트라면 라면 얻어먹은 정으로 용서해 준다)
- **📚 2학년 계열 선택**: 문과(인문·사회) / 이과(자연·공학). 퀴즈 과목 비중, 토론대회·과학탐구대회 이벤트, 졸업 진로가 달라진다
- **🌦️ 계절·날씨 사건**: 황사·미세먼지, 장마철 정전, 모기 대란, 폭염 에어컨 고장, 추수 봉사, 폭설 버스 중단, 보일러 고장
- **🛒 매점**: 책·마이쮸·프로틴·단짠 과자·귀마개·에너지 드링크 + 가방 아이템 🧢 변장 모자(무단외출 +20%), 📘 수능특강(퀴즈 힌트 2회)
- **🏆 업적 도감**: 27개 업적, 브라우저에 저장
- **👮 사감 해곤 쌤 호감도**: 봉사·심부름·자진 제출로 오르고 벌점을 받으면 떨어진다. 70 이상이면 벌점 -1·검사 느슨, 80 이상이면 무단외출 한 번 봐주기, 30 이하면 벌점 +1·검사 깐깐
- **👩‍🏫 담임 선생님 상담**: 성적이 좋으면 칭찬, 벌점이 많거나 성적이 나쁘면 교무실 호출, 3학년 진로 상담
- **🧳 전학생 도현**: 2학년 5월에 전학 와서 친구 또는 라이벌이 된다
- **🎂 생일**: 입학 때 생일 달을 고른다. 룸메 친밀도에 따라 깜짝 파티 또는 쓸쓸한 생일 (방학이면 집에서)
- **📄 족보 유출 유혹**: 내신 시험 전 족보를 볼지 선택. 성공하면 성적 대박, 걸리면(30%) 0점 + 벌점 15 + 명성 -15
- **📸 졸업 앨범 & 💌 룸메 편지**: 졸업하면 3년 하이라이트 앨범과 룸메 두 명의 편지(친밀도·옷장 사건에 따라 내용이 달라짐)
- **💥 위기 패널티** (전학 없음): 능력치가 20 미만이면 매 턴 스트레스 +15, 나머지 능력치 -4. 연속일수록 1.5배, 2배…로 세진다. 3학년 끝에 20 미만인 능력치가 있으면 졸업 사정 탈락
- 3학년 마지막에 수능(1~9등급). 모든 능력치 20 이상이면 졸업, 수능 등급에 따라 진로가 갈린다
- 진행 상황은 브라우저에 자동 저장되어 이어하기 가능

## 밸런스
규칙 부분(첫 번째 `<script>`)은 화면과 분리되어 있어 Node로 자동 시뮬레이션할 수 있다.
현재 설정(매 턴 자연 감소 지능 -6, 체력 -6, 사회성 -5, 명성 -4 / 스트레스 +21 / 월 귀가 스트레스 -4)에서 전략적으로 플레이하면 졸업률 약 70%, 아무렇게나 고르면 약 17% (퀴즈 실력은 시뮬레이션에 포함 안 됨).

## 웹사이트로 공개하기 (GitHub Pages)
저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`로, 브랜치와 `/ (root)` 폴더를 고르고 Save 하면
몇 분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 접속할 수 있습니다.

## 새 버전 올리는 법 (자동 업데이트)
`index.html` 안의 `APP_VERSION` 과 `version.json` 의 `"version"` 을 **같은 새 값**으로 바꿔서 올리면 된다.
- 접속 중인 사람: 1분 안에 "🔔 새 버전 대기 중" 알림 → 지금 판이 끝나고 '다시 입학하기'를 누르면 새 버전으로 시작
- 게임 중이 아닌 사람(첫 화면): 바로 새 버전으로 바뀜
- 하던 판은 끊기지 않는다
