# 🏫 풍산고에서 졸업하기

15턴을 버티고 풍산고를 졸업하는 텍스트 육성 게임입니다.

- `index.html` — 브라우저에서 바로 플레이하는 웹 버전 (설치 필요 없음)
- `pungsan_game.py` — 원본 Jupyter(ipywidgets) 버전

## 규칙 (웹 버전)
- 입학할 때 집중 능력치를 고르면 그 능력치는 60, 나머지는 50으로 시작
- 매 턴 활동 1개: 자습 / 체단실 / 장기자랑 / 동아리 / 봉사활동 / 무단외출
- **랜덤 이벤트**: 턴 시작 시 45% 확률로 사건 발생 (매점 빵, 야식 파티, 체육대회, 축제…), 선택에 따라 결과가 달라짐
- **사감 경계도**: 무단외출 적발 확률 = 15% + 경계도. 외출에 성공하면 +15, 매 턴 -5, 봉사활동 -15
- **시험 미니게임**: 3·6·9·12·15턴에 암산 3문제(문제당 6초), 맞힐 때마다 시험 점수 +5
- 턴이 끝날 때마다 모든 능력치 -3
- 지능·체력·사회성 중 하나라도 25 미만으로 2턴 연속이면 전학
- **엔딩 10종** (숨겨진 엔딩 포함), 본 엔딩은 브라우저의 엔딩 도감에 저장

## 웹사이트로 공개하기 (GitHub Pages)
저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`로, 브랜치와 `/ (root)` 폴더를 고르고 Save 하면
몇 분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 접속할 수 있습니다.
